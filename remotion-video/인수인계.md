# 해파리 만개 영상 · 인수인계 안내

학교 제출용 북 영상 「해파리 만개」에 나레이션과 배경 음악을 입히는 작업입니다.
영상 편집은 [Remotion](https://www.remotion.dev)(코드로 영상을 만드는 도구)으로 합니다.

## 1. 지금까지 된 것 (v1)

| 항목 | 상태 | 파일 |
|---|---|---|
| 원본 영상 | 받음 (1920×1080, 30fps, 4분 49초, **소리 없음**) | `해파리만개_전체_v3.mp4` (아래 2번 참고) |
| 나레이션 대본 | 53줄 정리 (13·43번은 중복이라 뺌) | `narration/script.json` |

| 배경 음악 v1 | 직접 합성한 앰비언트 음악 | `public/music/bgm.mp3` |
| 완성본 v1 | 렌더링 완료 | `해파리만개_주지스님_v1.mp4` |

## 2. 받은 피드백 · 남은 작업 (v2)

1. **나레이션이 너무 "읽는 느낌"** → 더 자연스러운 목소리로 바꾸기
   - Edge 무료 음성 8개 샘플: `목소리_후보_샘플.mp3`
   - 더 자연스러운 후보: **ElevenLabs 무료 플랜**(월 1만 자, 대본은 약 2천 자), 네이버 클로바더빙, 타입캐스트
   - 아직 서비스를 정하지 않음
2. **두 인물의 대화(33~47번)도 읽는 느낌** → 대화체로 자연스럽게, 쉼표·말줄임표로 숨 쉬는 지점 넣기
3. **배속 없애기**: v1은 긴 대사를 최대 1.6배로 빠르게 했는데, 모든 대사를 같은 속도로 맞추기.
   대사가 구간보다 길면 **그 부분 화면을 천천히 재생해서 시간을 늘리기**
   - 특히 **2:25~2:29 (#30 "수온, 먹이, 주변 환경 등…")** 은 늘려 달라는 요청
   - v1에서 빨라졌던 줄: #4, 10, 12, 15, 16, 21, 23, 25~31, 33, 36~39, 41, 50, 52, 54
4. **음악이 호러 같음** → 잔잔하면서 집중되는 차분한 음악으로 교체
   (밝은 장조, 피아노 위주, 긴 잔향·불협화음 없이)
5. 확인 필요: #38 "억죄된 것들"이 오타인지 ("옥죄던"? "억압된"?)

## 3. 작업 환경 만들기

준비물: [Node.js](https://nodejs.org) 22 이상, (나레이션을 다시 만들 때만) Python 3과 ffmpeg

```bash
cd remotion-video
npm i
```

원본 영상을 `public/haepari.mp4` 이름으로 넣습니다.
원본은 이 Drive 폴더나 GitHub 릴리스에서 받을 수 있습니다:
https://github.com/yeoni0515-pixel/ez_2-2/releases/tag/video-source

코드 전체는 GitHub에도 있습니다 (브랜치 `claude/quirky-rubin-vtnyyx`):
https://github.com/yeoni0515-pixel/ez_2-2/tree/claude/quirky-rubin-vtnyyx/remotion-video

## 4. 자주 쓰는 명령

| 하고 싶은 것 | 명령 |
|---|---|
| 미리보기 (브라우저에서 재생) | `npm run dev` |
| 최종 영상 만들기 → `out/해파리만개_주지스님.mp4` | `npm run render` |
| 나레이션 다시 만들기 (바뀐 줄만) | `pip install edge-tts` 후 `npm run narration` |
| 배경 음악 다시 만들기 | `pip install numpy scipy` 후 `python scripts/generate-music.py` |

## 5. 파일 구조

```
remotion-video/
├─ narration/
│  ├─ script.json        나레이션 대본 (시작·끝 초, 목소리, 대사)
│  ├─ voices.json        목소리 설정 (provider: "edge" 또는 "elevenlabs")
│  └─ cache/             생성된 원본 음성 (다시 만들 때 재사용)
├─ public/
│  ├─ haepari.mp4        원본 영상 (직접 넣기)
│  ├─ narration/         구간에 맞춘 나레이션 음성
│  └─ music/bgm.mp3      배경 음악
├─ scripts/
│  ├─ generate-narration.mjs   대본 → 음성 생성, 구간 맞춤 → src/narration-timing.json
│  └─ generate-music.py        배경 음악 합성
└─ src/
   ├─ HaepariManGae.tsx  영상 구성 (원본 영상 + 나레이션 + 음악, 나레이션 중 음악 30%→12%)
   └─ narration-timing.json    나레이션 배치 결과 (자동 생성)
```
